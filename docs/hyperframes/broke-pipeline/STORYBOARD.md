## Visual constraints

- Canvas: 1920 × 1080, MP4 at 30 fps; GIF at 15 fps and 1280 × 720.
- Ground `#0d130f` with subtle telemetry grid, warm white `#f7f4e8`, old context `#ff947e`, mint `#a5f2c5`.
- Hero type: Inter, 138–248 px; essential supporting copy and telemetry labels: 30–52 px.
- No fabricated UI, billing savings, paid music, voiceover, or flashing effects.
- Preserve the default pipeline's stored-history boundary. Optional features
  that modify history are outside this film's scope.
- Benchmark: `npm run bench`, deterministic 67-message synthetic session
  (351,403 input characters):
  - Default `truncate` mode: 238,333 output characters (113,070 removed, 32.2%).
  - Optional `summarize` mode: 36,140 output characters (315,263 removed, 89.7%).
  - Both figures are synthetic character reductions, not typical-workload or
    billing-savings promises. The comparison bars use the exact character ratios.
